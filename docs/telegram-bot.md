# Telegram-бот

Бот `@salon_eugenia_bot` («Салон красоты Евгения») присылает коды входа на сайт.
Клиент привязывает номер один раз. Бот принимает контакт только от владельца номера.

## Настройка в @BotFather

1. Откройте @BotFather и отправьте `/mybots`.
2. Выберите бота `@salon_eugenia_bot` и откройте `Edit Bot`.
3. `Edit Description` — вставьте текст:

> Бот салона красоты Евгения. Присылает код для входа на сайт онлайн-записи. Привяжите номер телефона один раз — нажмите «Поделиться номером».

4. `Edit About` — вставьте текст:

> Онлайн-запись салона красоты Евгения. Код входа на сайт приходит в этот бот.

5. `Edit Commands` — задайте команду:

> start - Привязать номер телефона

6. Токен бота берите в `API Token`. Где хранить токен — см. [security.md](security.md).

## Конфигурация

| Среда | Где задать |
|---|---|
| Dev | `Telegram:Bot:Token` и `Telegram:Bot:Username` в `backend/WebApi/appsettings.Development.json` |
| Docker | `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME` в `.env` |

Файлы `appsettings.Development.json` и `.env` в `.gitignore`.
Без токена dev использует `FakeCodeSender`: код пишется в лог API и приходит в ответе `send-code`.

## Поток входа

1. Клиент вводит телефон на сайте и нажимает «Получить код».
2. Привязки нет — сайт показывает кнопку «Открыть бота».
3. Клиент открывает бота и нажимает «Поделиться номером».
4. Бот отвечает: «Номер привязан. Вернитесь на сайт и нажмите «Получить код».»
5. Клиент нажимает «Получить код» ещё раз. Код приходит в бота.
6. Клиент вводит код и входит.
