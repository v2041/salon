# Метки triage

Скиллы используют пять канонических ролей triage. Файл сопоставляет роли с метками этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение |
|---|---|---|
| `needs-triage` | `needs-triage` | Мейнтейнеру нужно оценить issue |
| `needs-info` | `needs-info` | Ждём информацию от автора |
| `ready-for-agent` | `ready-for-agent` | Спека готова, можно отдать агенту |
| `ready-for-human` | `ready-for-human` | Нужна реализация человеком |
| `wontfix` | `wontfix` | Не будем делать |

Когда скилл называет роль, берите строку из таблицы.

Меняйте колонку «Метка в нашем трекере», если словарь изменится.
