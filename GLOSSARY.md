# Студия

Студия красоты одного мастера: онлайн-запись, услуги, расписание и аналитика.

## Language

**Запись**:
Визит клиента к мастеру: интервал времени в расписании дня, набор услуг, цена и статус.
_Avoid_: бронь, бронирование, визит, сеанс

**Предстоящая запись**:
Запись, время начала которой позже текущего момента. Статус не влияет на деление.
_Avoid_: будущая запись

**Прошедшая запись**:
Запись, время начала которой не позже текущего момента. Статус не влияет на деление.
_Avoid_: завершённая запись, прошлая запись, история

**Клиент**:
Посетитель студии. Записывается, смотрит и отменяет свои записи.
_Avoid_: пользователь, гость

**Мастер**:
Владелец студии, один человек. Управляет расписанием, записями и ценами.
_Avoid_: админ, администратор, владелец

**VK ID**:
Внешний сервис входа. Клиент входит только через него; студия получает имя и российский номер телефона.
_Avoid_: ВКонтакте, ВК, соцсеть

**Политика обработки персональных данных**:
Документ с версией: описывает, какие данные студия собирает и зачем. Клиент открывает его со страницы входа.
_Avoid_: оферта, соглашение, правила

**Согласие на обработку персональных данных**:
Факт согласия клиента с политикой: версия политики и дата. Записывается при каждом входе.
_Avoid_: галочка, чекбокс, акцепт
