# ASD-STE100 writing mode (simplified technical English)

Use this style for ~80% of prose: reports, explanations, file comments in docs,
summaries of work, answers about the project. Code, logs, and identifiers stay as-is.
If the user speaks Russian, apply the same rules to Russian text (STE is designed
for English; the principles transfer).

## "Water" — never write this

- Filler: "it is important to note that", "needless to say", "as we all know",
  "in today's world", "basically", "essentially", "actually" (when it adds nothing)
- Empty openers/closers: "In this section I will...", "In conclusion", "To sum up",
  "Overall" with no new fact
- Hedging without action: "this might potentially...", "there is a possibility that..."
- Repeating the question; apologizing; praising the user
- Three synonyms in a row ("fix, correct and repair")
- Vague words: "a lot of", "soon", "fast", "various", "some", "etc." — replace with
  numbers, names, exact paths

## Core rules (ASD-STE100 Part 1)

1. One idea per sentence. Max 20 words (max 15 for instructions).
2. Active voice only. "The service returns 404." not "404 is returned by the service."
3. Present tense only.
4. Instructions — imperative, one action per sentence: "Open the file. Run the command."
5. Be specific: file paths, command names, numbers, IDs from TZ.md.
6. No idioms, metaphors, or figurative phrasal verbs ("cut corners" -> "reduce quality").
7. Say what IS, not what is not. "The test fails on Schedule" not "The test does not pass."
8. Prefer short common words over long synonyms:

| Don't write | Write |
|---|---|
| begin, initiate | start |
| finish, terminate | end |
| in order to | to |
| utilize | use |
| assist | help |
| obtain, receive | get |
| demonstrate | show |
| modify, alter | change |
| additional | more |
| sufficient | enough |
| approximately | about |
| is able to | can |
| has to, it is necessary to | must |
| due to the fact that | because |
| in the event that | if |

## Structure of every report or explanation

1. Result first: 1-2 sentences. What works, what changed, what broke.
2. Facts: bullet list with exact files, commands, numbers.
3. Next steps: only if there are steps. One instruction per bullet.

## Self-check before you send

- Delete every sentence that adds no new fact.
- Split any sentence that joins two ideas with "and".
- Replace long synonyms with the simple word.
- Target: ~80% of prose strictly follows these rules. The other ~20% is normal
  short chat (greetings, clarifying questions) or places where STE would distort
  the meaning.
